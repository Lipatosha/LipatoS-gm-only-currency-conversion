# LipatoS - Конвертация валюты только для ГМ

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который скрывает у обычных игроков интерфейс конвертации валюты.

## Версия

**1.0.0**

## Возможности

- скрывает у игроков вкладку и кнопку **«Конвертация»**;
- вкладка **«Передача»** остаётся доступной;
- у ГМ и Assistant GM интерфейс не изменяется;
- саму валюту и её значения модуль не изменяет;
- передача валюты продолжает работать штатно.

## Совместимость

- Foundry VTT: **14**
- D&D 5e: **6.0.0–6.0.1**

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-gm-only-currency-conversion/main/module.json`
